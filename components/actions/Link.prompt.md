Inline text link for navigation inside copy.

```jsx
<Link>View plans</Link>
```

Renders `<s-link>`. Props (camelCase → lowercase attribute): tone, accessibilityLabel, lang, interestFor, download, target, command, commandFor, href.
Slots: (default). Events: click.
Plain-HTML equivalent (preferred in production): `<s-link>…</s-link>`.
