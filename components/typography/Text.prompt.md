Inline text with tone, color, weight and type (strong, address…).

```jsx
<Text tone="subdued">Last updated 26 Sep</Text>
```

Renders `<s-text>`. Props (camelCase → lowercase attribute): color, type, tone, fontVariantNumeric, fontSize, fontWeight, accessibilityVisibility, dir, interestFor.
Slots: (default). Events: none.
Plain-HTML equivalent (preferred in production): `<s-text tone="subdued">…</s-text>`.
