Formats and displays a number with tabular figures (wraps <s-number>).

```jsx
<NumberText></NumberText>
```

Renders `<s-number>`. Props (camelCase → lowercase attribute): tone, color, fontSize, fontWeight, accessibilityVisibility, dir.
Slots: (default). Events: none.
Plain-HTML equivalent (preferred in production): `<s-number>…</s-number>`.
