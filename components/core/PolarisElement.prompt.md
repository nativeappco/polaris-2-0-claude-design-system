Generic renderer for any s-* / ui-* custom element; use only when no named wrapper exists.

```jsx
<PolarisElement tag="s-box" padding="base" background="subdued">…</PolarisElement>
```

camelCase props → lowercase attributes; booleans present/omitted; onX → native listeners. Importing any component auto-loads https://cdn.shopify.com/shopifycloud/polaris-2.0-rc.js.
