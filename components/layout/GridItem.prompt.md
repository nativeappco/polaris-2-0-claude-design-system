A single cell inside s-grid that controls column/row span.

```jsx
<GridItem></GridItem>
```

Renders `<s-grid-item>`. Props (camelCase → lowercase attribute): gridColumn, gridRow, background, border, borderWidth, borderStyle, borderColor, borderRadius, padding, paddingBlock, paddingBlockStart, paddingBlockEnd, paddingInline, paddingInlineStart….
Slots: (default). Events: none.
Plain-HTML equivalent (preferred in production): `<s-grid-item>…</s-grid-item>`.
