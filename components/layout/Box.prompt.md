Generic container for token-based padding, background, border and radius.

```jsx
<Box padding="base" background="subdued" borderRadius="base">…</Box>
```

Renders `<s-box>`. Props (camelCase → lowercase attribute): background, border, borderWidth, borderStyle, borderColor, borderRadius, padding, paddingBlock, paddingBlockStart, paddingBlockEnd, paddingInline, paddingInlineStart, paddingInlineEnd, display….
Slots: (default). Events: none.
Plain-HTML equivalent (preferred in production): `<s-box padding="base" background="subdued" borderradius="base">…</s-box>`.
