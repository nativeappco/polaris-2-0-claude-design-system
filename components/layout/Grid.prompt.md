CSS-grid layout with token gaps; use for multi-column forms and dashboards.

```jsx
<Grid gridTemplateColumns="1fr 1fr" gap="base">…</Grid>
```

Renders `<s-grid>`. Props (camelCase → lowercase attribute): alignItems, justifyItems, placeItems, alignContent, justifyContent, placeContent, gap, rowGap, columnGap, gridTemplateColumns, gridTemplateRows, background, border, borderWidth….
Slots: (default). Events: none.
Plain-HTML equivalent (preferred in production): `<s-grid gridtemplatecolumns="1fr 1fr" gap="base">…</s-grid>`.
