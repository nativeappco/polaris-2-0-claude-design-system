Lays out children in a block or inline direction with token gaps.

```jsx
<Stack direction="inline" gap="base">…</Stack>
```

Renders `<s-stack>`. Props (camelCase → lowercase attribute): justifyContent, alignItems, alignContent, gap, rowGap, columnGap, direction, background, border, borderWidth, borderStyle, borderColor, borderRadius, padding….
Slots: (default). Events: none.
Plain-HTML equivalent (preferred in production): `<s-stack direction="inline" gap="base">…</s-stack>`.
