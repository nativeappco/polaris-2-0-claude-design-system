Scrollable region with fixed block size.

```jsx
<ScrollBox></ScrollBox>
```

Renders `<s-scroll-box>`. Props (camelCase → lowercase attribute): overflow, accessibilityRole, accessibilityLabel, snapType, scrollPadding, scrollMargin, accessibilityVisibility, background, blockSize, border, borderColor, borderRadius, borderStyle, borderWidth….
Slots: (default). Events: scroll, scrolltoedge.
Plain-HTML equivalent (preferred in production): `<s-scroll-box>…</s-scroll-box>`.
