Numeric input with min, max, step, prefix and suffix.

```jsx
<NumberField></NumberField>
```

Renders `<s-number-field>`. Props (camelCase → lowercase attribute): value, inputMode, id, disabled, details, error, label, required, name, labelAccessibilityVisibility, defaultValue, placeholder, readOnly, autocomplete….
Slots: error, details. Events: input, change, focus, blur.
Plain-HTML equivalent (preferred in production): `<s-number-field>…</s-number-field>`.
