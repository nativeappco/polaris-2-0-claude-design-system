Password input with hidden characters.

```jsx
<PasswordField></PasswordField>
```

Renders `<s-password-field>`. Props (camelCase → lowercase attribute): id, disabled, name, value, details, error, label, required, labelAccessibilityVisibility, defaultValue, placeholder, readOnly, autocomplete, maxLength….
Slots: error, details. Events: input, change, focus, blur.
Plain-HTML equivalent (preferred in production): `<s-password-field>…</s-password-field>`.
