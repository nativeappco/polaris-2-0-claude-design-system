Dropdown for choosing one option from a list of s-option.

```jsx
<Select label="Theme"></Select>
```

Renders `<s-select>`. Props (camelCase → lowercase attribute): value, icon, id, disabled, name, details, error, label, required, labelAccessibilityVisibility, placeholder.
Slots: (default), error, details. Events: change, input, blur, focus.
Plain-HTML equivalent (preferred in production): `<s-select label="Theme">…</s-select>`.
