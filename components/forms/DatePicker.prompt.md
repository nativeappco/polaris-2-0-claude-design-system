Inline calendar for a single date or a range.

```jsx
<DatePicker></DatePicker>
```

Renders `<s-date-picker>`. Props (camelCase → lowercase attribute): type, value, defaultValue, allow, allowDays, disallow, disallowDays, view, defaultView, visibleMonths, name.
Slots: none. Events: viewchange, focus, blur, input, change.
Plain-HTML equivalent (preferred in production): `<s-date-picker>…</s-date-picker>`.
