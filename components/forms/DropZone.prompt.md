Drag-and-drop file upload area.

```jsx
<DropZone></DropZone>
```

Renders `<s-drop-zone>`. Props (camelCase → lowercase attribute): accessibilityLabel, multiple, accept, disabled, error, label, required, name, labelAccessibilityVisibility, value, files.
Slots: (default). Events: change, input, droprejected.
Plain-HTML equivalent (preferred in production): `<s-drop-zone>…</s-drop-zone>`.
