Hex color input with swatch.

```jsx
<ColorField></ColorField>
```

Renders `<s-color-field>`. Props (camelCase → lowercase attribute): id, disabled, name, value, details, error, label, required, labelAccessibilityVisibility, defaultValue, placeholder, readOnly, autocomplete, alpha.
Slots: error, details. Events: input, change, focus, blur.
Plain-HTML equivalent (preferred in production): `<s-color-field>…</s-color-field>`.
