Polaris icon by name (see assets/icons/icon-map.json for all 560 names).

```jsx
<Icon type="product"></Icon>
```

Renders `<s-icon>`. Props (camelCase → lowercase attribute): type, tone, color, size, interestFor.
Slots: none. Events: none.
Plain-HTML equivalent (preferred in production): `<s-icon type="product">…</s-icon>`.
